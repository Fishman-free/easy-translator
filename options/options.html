Easy Translator 设置

通用

5 秒

本地小模型（OpenAI 兼容端点）

本地模型冷启动需要把权重读入内存（CPU 上可能 1–3 分钟）， 点「预热模型」可提前加载，之后每次查词只需几百毫秒。

本地 Ollama 用户：先执行 ollama pull qwen2.5:1.5b（文本）与 ollama pull qwen2.5vl:3b（视觉，用于图片取词）。 若浏览器提示 403，请设置环境变量 OLLAMA_ORIGINS=chrome-extension://* 后重启 Ollama。

图片取词

1.5 秒

图片中的文字会被截屏裁剪后发给本地视觉模型识别；识别不到英文单词时不会弹窗。 该功能需要授予「所有网站」权限（在扩展弹窗中点击「授权」）。

PDF

关闭时：检测到 PDF 会在扩展图标上显示 PDF 标记，点开扩展即可用内置阅读器打开。 已打开的 PDF 也可以直接拖进阅读器页面。
